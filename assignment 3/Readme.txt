## Objective

The objective of this assignment is to understand real-world data collection and data insertion in a relational database using SQL. This project involves collecting authentic academic data and inserting it into database tables using SQL queries.

---

## Project Description

This project contains SQL scripts for inserting real-world college data into the following database tables:

* Department
* Faculty
* Course
* Student
* Enrollment

All data has been collected from authentic academic sources and inserted using proper SQL commands while maintaining primary key and foreign key constraints.

## How to Run the Project

1. Open Oracle SQL Developer (or any SQL environment).
2. Create the database schema (from Lab-2).
3. Run the `insert_queries.sql` file.
4. Verify insertion using:

```sql

```

5. Check screenshots in the repository for output verification.
